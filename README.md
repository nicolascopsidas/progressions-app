# Progressions d’accords

Application web pour écouter et explorer des progressions d’accords (pop, jazz, blues, classique, impressionnisme) : choix de la tonalité, du tempo, du son et du style de jeu, grille d’accords et clavier interactifs, atelier pour composer sa propre progression.

Tout tient dans un seul fichier, `index.html` : le son est synthétisé en direct dans le navigateur (Web Audio), sans dépendance ni étape de build.

## Lancer en local

Ouvrir `index.html` dans un navigateur.

## GitHub Pages

Le site est servi tel quel depuis la racine du dépôt (le fichier `.nojekyll` désactive Jekyll).
